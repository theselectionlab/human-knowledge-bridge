# Human Knowledge Bridge — The Moon Detective

An interactive five-screen "Science Detective" experience for ages 8–12 that tells the
story of the Apollo 11 Passive Seismic Experiment — hardware NASA left on the Moon —
and teaches children to tell measured evidence, scientific conclusions, and scientific
models apart.

Built for the NASA Space Apps Challenge 2026, "Abandoned but not Forgotten".

This is an independent project. It is not an official NASA product and is not endorsed
by NASA.

**Status:** in build.
