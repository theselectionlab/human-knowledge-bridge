## Design reference

The five-screen flow and the visual direction were informed by Selection Lab's
internal clickable reference prototype (November 2026). No code, CSS or JavaScript
from that reference is included in this repository.

## Third-party code

None. No frameworks, libraries, fonts, icon sets or analytics are bundled or loaded at
runtime. The type faces are the fonts already installed on the reader's device.

## NASA brand

This is an independent project for the NASA Space Apps Challenge. It is not an official
NASA product and is not endorsed by NASA. The NASA insignia, logotype and identifiers
are not used anywhere in this repository or the live demo.
